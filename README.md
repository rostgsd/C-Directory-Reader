# C# Directory-Reader
Simple program to display a filesystem in the console with pretty colors
clone then run using .NET
Options:
-startcolor, -endcolor: sets start and end values for color gradient such as red, green, blue, etc
-analysismode: color code files by file size, extension, date creation, or alphebetical
-samplesize: sets maximum amount of colors that can be used
-ignorehiddencontents: as straightforward as it sounds
